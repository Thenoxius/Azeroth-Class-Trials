# Azeroth Class Trials

A small real-time combat game that helps you pick a main for **World of Warcraft: Forever**: play Hunter, Mage and Priest through five short trials (questing, an ambush, a dungeon, a duel and a raid boss) and compare how each class felt.

**Play it:** https://thenoxius.github.io/Azeroth-Class-Trials/

Progress is stored in your own browser only.

## Development

```bash
npm install
npm test          # bot-driven balance and kit tests
npm run build     # dist/index.html (artifact) and dist/preview.html (standalone page)
```

Every push to `main` runs the tests, builds the game and publishes it to GitHub Pages (`.github/workflows/pages.yml`).

Art: `src/ui/art/img/` holds the resized portraits and spell icons as content-hashed WebP files (`art-images.gen.js` maps IDs to them). The site loads them as separate files; the claude.ai artifact build inlines them. They are generated by `npm run art` from the approved masters in `art-source/`, which are kept out of the repository because of their size. Spell icon artwork © Blizzard Entertainment; this is a non-commercial fan project.

## Local working copy

Use this project directory as the active checkout. The implementation is on branch codex/azeroth-local; phase4 is preserved. Run npm start (or npm run dev) to build and serve at http://127.0.0.1:4174. Stop with Ctrl+C and restart after source edits. Validation reports and screenshots are in docs/local-validation/.
