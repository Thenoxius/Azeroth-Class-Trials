# Azeroth Class Trials

A small real-time combat game that helps you pick a main for **World of Warcraft: Forever**: play Hunter, Mage, Priest, Warrior, Rogue and Shaman through six short trials (questing, an ambush, a dungeon, a duel, a raid boss and a target dummy with a leaderboard) and compare how each class felt. Desktop only.

**Play it:** https://classtrials.com

Progress is stored in your own browser only.

## Development

```bash
npm install
npm test          # kit, trial, analysis and save tests with bots
npm run build     # dist/index.html (artifact) and dist/preview.html (standalone page)
npm run format    # Prettier; CI fails on unformatted code
```

Every push to `main` runs the tests, builds the game and publishes it to GitHub Pages (`.github/workflows/pages.yml`).

Art: `src/ui/art/img/` holds the resized portraits and spell icons as content-hashed WebP files (`art-images.gen.js` maps IDs to them). The site loads them as separate files; the claude.ai artifact build inlines them. They are generated by `npm run art` from the approved masters in `art-source/`, which are kept out of the repository because of their size. Spell icon artwork © Blizzard Entertainment; this is a non-commercial fan project.

## Local working copy

Use this project directory as the active checkout, on branch `codex/azeroth-local`. Run `npm start` to build and serve at http://127.0.0.1:4174; restart after source edits. Status, what is missing and how to regenerate art: `design/phase4-progress.md`.
